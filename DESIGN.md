# Design System (`earth-google`)

Adapted from [OpenDesignMD — `earth-google`](https://opendesignmd.com/designs/earth-google/).

## Color Palette
| Token | Hex | Role |
| :--- | :--- | :--- |
| `--action` | `#1A73E8` | Primary buttons, selected nav pills, active river highlight |
| `--action-soft` | `#8AB4F8` | Secondary accent, active chips, chart curves, links |
| `--canvas` | `#000000` | Full-bleed map stage |
| `--surface` | `#000000` | Top bar, quiet controls, KPI card inset |
| `--surface-raised` | `#1F1F1F` | Inspector sheet, modal sheets |
| `--surface-alt` | `#26282C` | Persistent left navigation rail |
| `--border` | `#33363B` | `1px` hairline outlines (depth via layering, no heavy drop shadows) |
| `--ink` | `#E8EAED` | Primary text |
| `--muted-ink` | `#A1A6AD` | Supporting labels, metadata |

## Typography
- **Primary UI (`--font-ui`):** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
  - Inspector headline: `1.25rem` / `600` / `-0.01em`
  - Card & nav items: `0.9rem–1rem` / `500–600`
  - Micro labels: `0.7rem` / `500` / `uppercase` / `0.04em` tracking
- **Attribution & Legal (`--font-legal`):** `Times, "Times New Roman", serif` at `0.74rem` / `400`.
